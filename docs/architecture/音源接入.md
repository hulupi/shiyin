# 音源接入

本次增加的是音源与在线搜索/播放链路，未执行真实音源、平台接口或浏览器功能测试。编译通过不等同于脚本兼容性验收。

## 模块关系

- `frontend/src/components/SourceManager.vue`：导入、检查初始化、排序、启停和删除。
- `frontend/src/pages/search.vue`：平台切换、搜索、分页和播放入口。
- `backend/src/modules/sources/service.ts`：脚本文件、能力持久化及 Worker 生命周期。
- `backend/src/modules/sources/scheduler.ts`：平台/音质筛选、顺序尝试、超时、取消与冷却。
- `backend/src/source-runtime/worker.mjs`：QuickJS WebAssembly 隔离引擎；脚本本身不在 Node 全局执行。
- `backend/src/source-runtime/bootstrap.js`：在 QuickJS 内提供 lx 事件、请求和常用工具。
- `backend/src/modules/sources/network.ts`：解析并固定公网 DNS 地址、逐跳检查重定向、限制响应大小。
- `backend/src/modules/catalog/service.ts`：平台搜索和歌曲标识归一化、在线曲目持久化。
- `backend/src/modules/playback/online.ts`：本地绑定优先、在线取链、带鉴权音频代理与封面/歌词接口。

音源脚本导入后需要初始化成功并声明支持的平台与音质，不以解析头注释代替实际初始化。“检查初始化”会运行脚本，但不选歌取链。每次取链会启动新的隔离实例，脚本内存状态不会跨取链请求保留。

## 运行约束

单脚本最多 1 MB；最多 20 个脚本；QuickJS 内存上限 32 MB；单次同步执行约 1 秒中断；单次初始化/取链实例最多 15 秒。脚本 HTTP 同时最多 16 个、单实例累计最多 64 次，响应最多 4 MB。外部网络不允许访问本地、私有与保留地址。

初始化环境提供 `window`/`self` 指向隔离全局对象，但没有 DOM、文件系统、系统命令、Node 模块加载器。脚本只能通过桥接 API 获取受控宿主能力。普通 Node VM 不作为安全边界。

## 本地匹配与音源兜底

在线歌曲和本地文件通过确认后的显式绑定关联；歌名、歌手和时长仅用于生成候选。保存绑定后，后续搜索、收藏、历史或队列播放优先使用本地文件和歌词。

在线取链按目标音质遍历已启用且支持该平台的脚本，然后依次降低音质；验证链接可打开后才交给浏览器。浏览器解码或读取失败时排除该次失败音源，继续请求其他音源。已绑定但浏览器不能播放的本地文件允许跳过本地继续在线兜底。跨平台歌曲不自动互换。

播放地址保存在短期服务端租约中，客户端使用同源代理地址，不将签名链接作为永久曲目地址。代理仅使用已解析租约，不接受任意目标 URL。

## 兼容范围与限制

支持官方 lx 初始化/请求事件、回调式 HTTP 请求、基础 Buffer、MD5、AES、RSA、随机字节和压缩工具。提供基础 URL、URLSearchParams、文本编码及一次性定时器。完整浏览器 DOM、fetch、Node 模块、私有宿主接口、所有 Buffer 方法与复杂 URL 属性编辑不在当前兼容承诺内。

当前在线歌词优先读取平台提供的歌词地址，随后尝试支持 `local/lyric` 的脚本；网易云另有平台歌词补全。其他平台若没有歌词地址且脚本不提供歌词，将展示暂无歌词。封面缺失时使用占位，不生成虚构封面。
