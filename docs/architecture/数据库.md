# 数据库

应用使用 Node.js 内置 `node:sqlite` 的 SQLite 数据库，无需独立数据库服务。项目要求 Node.js 22.18 或以上；现有 Node.js 22.21 可使用。

默认数据库为 `backend/data/shiyin.sqlite`，设置 `SHIYIN_DATA_DIR` 后位于指定数据目录中。启用 WAL 日志、事务与外键。运行时可能同时出现 `shiyin.sqlite-wal`、`shiyin.sqlite-shm`，属于数据库工作文件。

## 数据表

| 表 | 用途 |
| --- | --- |
| `settings` | 音源设置 |
| `directories`、`local_tracks` | 音乐目录、本地歌曲索引 |
| `online_tracks` | 已收藏、播放或加入歌单的在线歌曲元数据 |
| `favorites`、`history` | 收藏关系和历史顺序 |
| `playlists`、`playlist_tracks` | 歌单和有序歌曲关系 |
| `downloads` | 下载任务及歌词封面补全状态 |
| `sources`、`source_scripts` | 音源元数据、私有脚本正文 |
| `bindings` | 在线歌曲和本地文件关联 |

歌曲索引按目录与标题建索引，本地搜索直接查询数据库中的标题、歌手、专辑。各记录的扩展元数据以 JSON 文本列保留在数据库记录内，集合和关联分别建表。

## 使用与备份

升级后重启 `npm run dev` 或生产服务。已有歌曲重新扫描一次可补充本地音质与码率信息。搜索首先显示本地匹配，再追加在线结果；“本地”标签仅查询本地音乐。

备份当前数据前先正常停止服务，再备份整个应用数据目录；音频及旁文件目录单独备份。恢复时使用同一份完整备份，避免混用不同时间的数据库和 WAL 文件。

本次执行前端构建与后端 TypeScript 编译检查，迁移、检索、歌单、下载等实际功能由用户手动验证。
