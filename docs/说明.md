# 拾音运行与打包说明

需要 Node.js 22.18 或更新版本。除特别说明外，命令都在仓库根目录执行。首次使用或锁文件更新后，先安装根目录依赖。

```sh
npm ci
```

## 网页版

开发时同时启动前端和后端：

```sh
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。Vite 会把 API 请求代理到本机后端。

构建并运行：

```sh
npm run build
npm start
```

前端产物位于 `frontend/dist/`。后端会同时提供页面和 API，默认访问 `http://127.0.0.1:3180`。需要更改监听地址、端口或数据目录时，在启动环境里设置 `HOST`、`PORT`、`SHIYIN_DATA_DIR`，参考 [环境变量示例](../.env.example)。

## 飞牛 fnOS（FPK）

准备当前系统可运行的 fnpack。Windows 默认读取 `backend/data/fnpack.exe`，Linux 和 macOS 默认读取 `backend/data/fnpack`。也可以用环境变量 `FNPACK_PATH` 指定工具路径。

```sh
npm run package:fpk
```

产物位于 `fpk/shiyin-<版本>-all.fpk`。在飞牛应用中心手动安装并启动拾音，然后从飞牛桌面打开，网关入口为 `/app/shiyin/`。工具版本、目录授权与安装验证见 [FPK 打包与安装](fpk打包.md)。

## Windows 桌面版

桌面端独立安装依赖。本地调试时先构建运行时，再启动 Electron：

```powershell
npm --prefix desktop ci
npm --prefix desktop run build:runtime
npm --prefix desktop start
```

修改前后端后重新构建运行时。重启之前，从托盘右键选择「退出」。

生成 Windows x64 安装包：

```powershell
npm --prefix desktop run package:win
```

产物位于 `desktop/dist/local/Shiyin-Local-Setup-<版本>-x64.exe`。如果 Electron 压缩包下载超时，并且 `desktop/node_modules/electron/dist/electron.exe` 已存在、版本与桌面端依赖一致，可以直接复用本机已解压的 Windows x64 Electron：

```powershell
npm --prefix desktop run package:win -- --config.electronDist=node_modules/electron/dist
```

如果 `npm ci` 报 `EPERM unlink` 且指向 Rolldown 的 `.node` 文件，先停止正在使用该仓库的 Vite 开发服务，再重跑 `npm ci`。

## Android

需要 Android Studio 和 Android SDK 36。用 Android Studio 自带的 JDK 构建，或在终端配置兼容的 JDK 和 Android SDK。

Android 客户端通过 HTTPS 连接已部署的拾音服务。把下面的示例地址改成手机能访问的拾音首页。如果部署在子路径，填写包含子路径及末尾斜杠的完整地址。地址会写入安装包，修改后需要重新同步并构建。

```powershell
$env:SHIYIN_ANDROID_SERVER_URL = 'https://music.example.com/'
npm run android:sync
npm run android:open
```

在 Android Studio 选择模拟器或已连接的手机，点击 Run。也可以在 PowerShell 生成调试 APK：

```powershell
Push-Location android
.\gradlew.bat assembleDebug
Pop-Location
```

在 macOS 或 Linux 终端用 `export SHIYIN_ANDROID_SERVER_URL='https://music.example.com/'` 设置地址，并用 `(cd android && ./gradlew assembleDebug)` 构建。调试包位于 `android/app/build/outputs/apk/debug/app-debug.apk`。正式分发需在 Android Studio 生成签名 APK 或 AAB。详见 [Android 客户端说明](../android/README.md)。
