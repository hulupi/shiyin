# 拾音

拾音是为飞牛 fnOS 打造的音乐应用。扫描 NAS 上的音乐和歌词，即可建立自己的音乐库，也能搜索多个平台，并通过导入的自定义音源播放和下载歌曲。

支持本地优先播放、同步歌词、收藏、歌单和播放历史。可通过 FPK 安装到飞牛 NAS，详见 [FPK 打包与安装](docs/fpk打包.md)。

## 本地开发

需要 Node.js 22.18 或更新版本及 npm。

在项目根目录（含 `package-lock.json`）运行以下命令。根目录的 npm Workspaces 配置会统一安装 `frontend` 和 `backend` 的依赖。

```sh
npm install
npm run dev
```

安装后，根目录、`frontend` 和 `backend` 下可能各有一个 `node_modules`。npm 会尽量把依赖提升到根目录，需要单独安装的依赖会留在对应的工作区目录中。这些目录由 npm 管理，无需手动合并。

前端默认地址为 `http://127.0.0.1:5173`，后端默认 `http://127.0.0.1:3180`。打开后直接进入音乐空间，在“设置”输入服务器上的音乐目录绝对路径。Windows 开发时填写 Windows 路径，NAS 部署时填写 NAS 路径。

前端开发服务将 `/api` 代理到后端。服务器只绑定本机；部署时通过环境变量 `HOST`、`PORT` 和 `SHIYIN_DATA_DIR` 设置监听地址、端口和应用数据目录。示例见 `.env.example`，应用不会自动读取 `.env`，需通过运行环境注入。

```sh
npm run build
npm start
```

上述构建命令生成 Web 静态文件，后端同时提供静态资源与 API。`npm start` 当前依赖 tsx 运行 TypeScript。FPK 会将后端编译为 JavaScript，运行时无需 tsx。

## 已实现代码范围

- Vue 深色响应式界面、底部播放器、播放队列、搜索、收藏及播放历史。
- 免登录使用，打开页面即可访问音乐库与设置。
- 多目录递归扫描、标签与封面读取、同名 LRC 关联、增量索引、取消扫描。
- 本地音频范围读取、四种播放模式、歌词时间高亮、自动跟随与点击跳转。
- 洛雪音源文件导入、初始化能力检查、启停、优先顺序、删除，支持最多 20 个音源。
- QuickJS WebAssembly + 独立 Worker 运行环境，受控 HTTP、内存/执行时间限制，不向脚本开放 Node.js 模块。
- 网易云、QQ、酷我、酷狗、咪咕的在线搜索适配代码，单平台失败不阻塞其他结果。
- 本地绑定优先、多音源顺序解析、音质降级、代理流播放、浏览器播放失败后继续换源。
- 在线收藏与历史、本地版本确认绑定，以及按来源能力读取封面和歌词。
- 在线榜单与公开歌单浏览，支持查看榜单和歌单中的歌曲。
- 批量下载，以及在下载管理中批量取消排队、重试失败任务、补全歌词和封面。
- 创建和删除个人歌单、添加歌曲、单首或批量移除歌曲。
- 在「设置 → 备份与恢复」导出和恢复 JSON 备份，涵盖收藏、播放记录、歌单、应用设置和音源脚本等。

持久化使用 Node.js 内置 SQLite，数据库位于 `backend/data/shiyin.sqlite`（可通过 `SHIYIN_DATA_DIR` 修改目录）。首次启动时创建数据库。歌曲、歌词和封面仍保存在用户选择的音乐目录。服务重启后可直接继续使用。详见 [数据库说明](docs/architecture/数据库.md)。

页面拆分和构建命令见 [目录结构与模块职责](docs/architecture/目录结构.md#前端页面拆分)。

前后端使用独立应用目录，共享协议与适配代码放在 packages 中。

## 使用在线音源

1. 重启 `npm run dev` ，在“设置 → 多音源管理”导入 UTF-8 `.js` 洛雪音源文件或通过公网脚本直链在线导入（单脚本最多 1 MB）。
2. 初始化成功后查看平台与音质能力，用上下按钮调整顺序，按需启停多个脚本。
3. 在设置中选择默认在线播放音质，进入“搜索”输入关键词并选择平台。
4. 首次发现同名同歌手且时长相近的本地版本时，确认是否绑定；确认后以后优先使用本地文件和歌词。
5. 没有可用本地绑定时，按音源顺序尝试目标音质，再逐级降低；播放器悬停提示实际音源，控制区显示实际音质。

“检查初始化”仅检查脚本能否运行并声明能力，不代表每首歌曲都能取链。没有内置或自动下载第三方音源，不保证所有现有脚本都兼容。

当前兼容范围为 lx 事件协议、回调式 request、常用 Buffer/AES/MD5/RSA/随机数及压缩工具，提供基础 URL/文本编码/定时器。完整 DOM、Node.js 模块、fetch、私有宿主 API、所有 Buffer 扩展方法暂未实现；脚本依赖这些功能时会提示初始化或解析失败。

平台搜索与音源取链是独立链路；搜索有结果不代表音源具备该平台的播放能力。接口适配未做真实网络功能验证。歌词和封面是否齐全取决于平台返回及脚本声明；无歌词时仍可播放。

私有音源脚本、音源设置、已选择的在线歌曲及本地关联均存放于 SQLite 数据库，应用数据目录被 Git 忽略。

协议与适配参考来源见 [音源接入说明](docs/architecture/音源接入.md)。

## 搜索结果与更多操作

本地音乐、搜索、收藏、历史和歌单使用统一的歌曲列表及更多操作。搜索先显示匹配的本地歌曲，再追加在线平台结果，支持单独筛选“本地”。列表显示封面、音质标记、歌手、平台、专辑，以及最高可用档位对应的格式和大小。详情弹窗可查看各个档位的规格；这些是平台提供的元数据，取链结果可能不同，未知字段不估算。酷我、酷狗封面使用独立平台请求补全，图片通过受控代理读取并缓存。

点击每行的“···”可播放、设为下一首、加入队列、收藏、加入歌单、查看详情或下载。“下一首播放”优先于随机选择。歌单可新建、添加/移除歌曲、整单播放与删除，记录保存在数据库的歌单和歌单歌曲表。

下载弹窗选择音质和已授权的可写 NAS 音乐目录。当前并发为 2；支持任务排队、取消、失败重试和完成后另存到浏览器设备。不覆盖同名文件，不同源的字节不拼接；完成后检测实际音频格式、自动入库并保存在线/本地绑定。任务保存在数据库的下载任务表。服务重启后未完成任务标记为失败，由用户重试。当前不提供暂停续传。下载完成后会获取歌词及封面，写入支持的音频标签并保存旁文件。

本次只完成构建与后端类型检查，未进行真实平台、封面、歌单操作或下载的功能测试。

## 下载歌词和内嵌封面

新下载默认获取歌词、封面，保存同名 UTF-8 `.lrc` 和原格式图片。MP3 使用 ID3 歌词/同步歌词/封面标签；FLAC 使用 Vorbis Comment 歌词和 PICTURE 封面块，同时写入歌曲名、歌手、专辑。音频压缩数据流直接复制，不重新编码。先写入新的临时文件、重新读取标签确认后再替换；失败则保留原音频并在任务里展示提示。

M4A、AAC、WAV、OGG 当前仅保存歌词和封面旁文件，不宣称已完成内嵌。封面与歌词是否可取得仍取决于平台和音源。没有取得的资源会显示提示，不生成空歌词文件。

旧任务可在“下载管理”点击“补全歌词封面”。成功保存的 LRC 可单独下载到浏览器设备。已有同名旁文件不会被覆盖；本地扫描和播放器同时支持同名封面/歌词与内嵌标签。播放器是否能读取内嵌同步歌词还取决于所用播放器，保留 LRC 便于兼容。

实现参考：[node-id3](https://github.com/Zazama/node-id3)、[FLAC RFC 9639](https://www.rfc-editor.org/rfc/rfc9639.html)。只执行编译与类型检查，实际标签写入、下载与播放器兼容性由用户手测。

## 界面组件

Element Plus 全局注册，使用简体中文语言包和深色主题，主题色统一为绿色。表单、输入框、按钮、选择框、上传、滑块、提示、更多菜单、确认框、歌曲弹窗及播放队列分别使用对应组件；确认或输入框取消后正常退出操作。功能由用户手测，仅执行构建与类型检查。

操作反馈使用短暂的 `ElMessage`，不再保留跨页面顶部通知。歌曲列表、歌单、下载、队列及配置列表统一使用 `ElPagination`，默认每页 50 条；完整分页支持切换 100/200 条。在线搜索按合并结果分页，本地匹配始终排在在线结果前。下载管理使用可筛选、可搜索、可展开详情的 Element Plus 表格，轮询刷新保留当前筛选与页码。
